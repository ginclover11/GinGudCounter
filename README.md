ESPAÑOL

              
              
Bajá el `.exe` desde la sección [Releases](../../releases)

## Uso en OBS

1. Abrí el programa
2. Copiá la URL que aparece en la parte de arriba del programa
3. En OBS: **+ → Browser Source**
4. Pegá la URL y ajustá el ancho para que coincida con tu overlay

## Logos de juegos

No puedo subir los logos por temas de copy y que me lo tiren, pero les recomiendo https://www.steamgriddb.com/ para descargarlos, tienen buena calidad y la resolucion perfecta
Poné los logos en la carpeta `assets/` con estos nombres exactos para cada juego:

```
assets/
  sekiro_logo.png
  ds1_logo.png
  ds2_logo.png
  ds3_logo.png
  elden_ring_logo.png
  bloodborne_logo.png
  demon_souls_logo.png
```

Se aplican automáticamente al iniciar un run con el template correspondiente.
De momento solo funciona con juegos de FromSoftware pero puedes crear tu propio template y cargar el logo del juego en cuestion

## OBS Setup

1. Open the program
2. Copy the URL shown at the top of the app
3. In OBS: + → Browser Source
4. Paste the URL and adjust the width to match your overlay

## Default Hotkeys

| Boss Hit | F1 |
| Block | F2 |
| On way hit | F3 |
| Start Timer | F4 |
| Stop Timer | F5 |
| Reset Boss split | F6 |
| Set PB | F7 |
| Next Boss | F8 |
| Previous Boss | F9 |
| Reset Run | F10 |

## Game logos for the overlay

Can't include logos due to copyright, but i do recomend https://www.steamgriddb.com/ it has high quality assets in the right resolution.
Place your logos in the assets/ folder using these exact filenames:

```
assets/
  sekiro_logo.png
  ds1_logo.png
  ds2_logo.png
  ds3_logo.png
  elden_ring_logo.png
  bloodborne_logo.png
  demon_souls_logo.png
```

Logos are applied automatically when starting a run with the matching template.
Currently ships with FromSoftware presets, but you can create your own templates and load any game logo you want
